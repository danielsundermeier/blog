# Der Konkurrent ist ein Sensor

In einem ungewohnten Supermarkt fällt mir die Orientierung schwer. Die Waren scheinen anders sortiert zu sein als erwartet. Vielleicht folgt die Anordnung weniger festen Kategorien und stärker der Frage, welche Dinge Menschen gemeinsam kaufen.

Ich weiß nicht, ob diese Vermutung stimmt. Aber sie verändert meinen Blick auf Strategie.

Ein Unternehmen kann versuchen, sein eigenes System für einen bestimmten Zweck besser zu gestalten. Es kann Wege verkürzen, Abläufe vereinfachen oder ein Bedürfnis genauer verstehen. Seine Energie fließt dann in die eigene Fähigkeit, ein Problem zu lösen.

Es kann seine Energie auch darauf richten, dass ein anderes Unternehmen weniger erfolgreich ist.

Beides kann von außen ähnlich aussehen. Eine neue Filiale neben einem bestehenden Markt kann Nachfrage dort bedienen, wo bereits Menschen einkaufen. Sie kann Teil einer Standortlogik sein. Sie kann aber auch aus einer Strategie entstehen, deren Erfolg daran gemessen wird, ob der andere verliert.

Der interessante Unterschied liegt nicht zuerst in der sichtbaren Handlung. Er liegt in der Beziehung zum Signal.

Wenn Menschen lieber ein anderes Angebot wählen, antwortet die Realität. Darauf kann ein Unternehmen grundsätzlich in zwei Richtungen reagieren.

Es kann versuchen, das Signal zu verändern: Wechsel erschweren, Alternativen blockieren, Aufmerksamkeit binden oder den Konkurrenten schwächen.

Oder es kann versuchen, das Signal zu verstehen: Welches Bedürfnis wird dort besser erfüllt? Was hat das andere System gesehen, das im eigenen Modell fehlt? Müssen beide überhaupt dasselbe Problem lösen?

In diesem Sinn ist der Konkurrent nicht nur Gegner. Er ist ein Wahrnehmungsorgan.

Sein anderes Angebot ist ein Experiment in derselben Realität. Menschen vergleichen die Ergebnisse durch ihre Entscheidungen. Wer den Konkurrenten ausschaltet, kann deshalb zugleich einen Sensor ausschalten, der eine eigene Verzerrung sichtbar gemacht hätte.

Das setzt allerdings ein anderes Ziel voraus. Wenn das Unternehmen selbst unbedingt fortbestehen muss, wird jedes bessere Angebot zur Bedrohung. Wenn der eigentliche Gegenstand das Problem ist, kann der Erfolg eines anderen dagegen eine gute Nachricht sein.

Dann wird das Unternehmen zu einer temporären Struktur:

Ein Problem wird sichtbar. Menschen bilden ein Holon darum. Sie führen Experimente durch, lernen und bauen eine Lösung. Funktioniert sie zuverlässig, wird sie verbreitet, standardisiert, automatisiert oder zur Infrastruktur. Die menschliche Kapazität wird für das nächste ungelöste Problem frei.

Das Unternehmen ist Gerüst, nicht Monument.

Eine solche Haltung beendet weder Handel noch unterschiedliche Angebote. Sie verschiebt nur die Frage. Nicht: Wie erhalten wir diese Organisation möglichst lange? Sondern: Wie gut erfüllt sie noch die Aufgabe, für die sie entstanden ist?

Auch ein Preis lässt sich dann anders lesen. Ein hoher oder steigender Preis kann anzeigen, dass eine Fähigkeit noch viel knappe Arbeit, Material, Wissen oder Koordination bindet. Er ist ein Signal, kein vollständiges Urteil. Manche Probleme erzeugen wenig Zahlungsfähigkeit und großes Leid. Andere werden Menschen aus Neugier verfolgen, obwohl kaum ein Markt sie belohnt.

Deshalb braucht dezentrale Koordination mehrere Signale. Preise können Aufmerksamkeit auf Knappheit lenken. Eigene Neugier und eigenes Unbehagen machen Probleme sichtbar, die für einen Menschen besonders lesbar sind. Nachvollziehbare frühere Arbeit kann zeigen, wem andere zusätzliche Kapazität anvertrauen möchten.

Reputation muss dafür nicht als Punktestand gebaut werden.

Sie kann als Nebenprodukt einer sichtbaren Geschichte entstehen: Was wurde beobachtet? Welche Versuche wurden unternommen? Was ist gescheitert? Was wurde gelernt? Welche Lösung existiert tatsächlich, und was hat sie bewirkt?

In räumlicher Nähe entsteht ein Teil dieses Vertrauens durch gemeinsames Erleben. Menschen sehen einander handeln, helfen und korrigieren. Lernen muss deshalb nicht lokal bleiben. Dokumentierte Erfahrungen können weltweit verfügbar werden, ohne dass eine zentrale Instanz alle Menschen in einer Zahl bewertet.

So können viele unterschiedliche Perspektiven parallel an der Realität lernen. Niemand besitzt die vollständige Karte. Jeder sieht aufgrund seiner Fähigkeiten, Erfahrungen und Interessen einen anderen Ausschnitt. Werden die Lernwege nachvollziehbar geteilt, muss nicht jeder bei null beginnen.

Aus einem gelösten eigenen Problem kann Infrastruktur für andere werden. Aus einer kleinen nachweisbaren Lösung kann Vertrauen für eine größere gemeinsame Aufgabe entstehen. Mehr Vertrauen ermöglicht größere Gruppen, größere Experimente und schwierigere Probleme.

Das Ziel ist dabei nicht, dass eine Organisation gewinnt.

Das Ziel ist, dass die Lösung tragfähiger wird und der nächste Zyklus mit mehr Kapazität beginnt.

Dann verändert sich auch der Blick im Supermarkt. Das ungewohnte Regal ist nicht einfach falsch. Es kann der sichtbare Rest eines anderen Modells sein.

Und der Konkurrent ist vielleicht genau der Sensor, der uns zeigt, was wir selbst noch nicht sehen.
