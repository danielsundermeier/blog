# Entwürfe

Dieses Verzeichnis enthält noch nicht freigegebene Artikel.

Jeder Entwurf verwendet das Format aus `../.agents/conventions/artikel.md`.

Dateien folgen dem Muster:

`YYYY-MM-DD Titel.md`

Ein Entwurf durchläuft abwechselnd Autor und Editor. Nach einer ausdrücklichen menschlichen Freigabe kann er in den Stamm des Blog-Repositories verschoben werden.
